# auro-carousel — translation of unaddressed options (placeholder)

Judgement-based translations, not name-matched ones, so none of this is bound yet. Replace each `n/a` with `attr="value"` (forward table) or `Property = Option` (reverse tables), or `n/a` if there is no code equivalent. Items marked **verify** are lower confidence and should be checked against the design or the component source before binding. Rows are generated by `build-translate.mjs`, which only adds missing rows and never edits existing ones (it only comments rows that look obsolete; `--prune` removes those whose target is gone).
